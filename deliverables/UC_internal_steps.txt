Name: Book a seat 
Actor: Student

1. The student opens the venue browse page and selects the desired amenities.
2. The system retrieves all venues matching the criteria.
3. The system displays the venues retrieved.
4. The student chooses a venue and starts the reservation process.
5. The student logs in.
6. The system displays all the available dates for the next two weeks. 
7. The student selects a date. 
8. The system requests reservation details. 
9. The student provides the requested information.
10. The system registers the reservation.
11. The system displays a confirmation of the reservation.

Extensions: 
2a. The system cannot retrieve venue data: The system displays an error message and terminates the use case.
3a. No venues match the filters: The system informs the user that no venues were found and prompts them to modify the criteria.
4a. The venue owner has not activated online reservations: The system displays an "Online booking service not available for this venue" message and terminates the use case. 
9a. The student omits mandatory information: The system asks the user to provide the complete information.
